# Fast Quiz — Frontend

Vue 3 + Vite web client for Fast Quiz. See `CLAUDE.md` and `../PROJE.md`.

## Local setup

Requires Node.js 22 and the backend running at `http://localhost:8000`.

```bash
cp .env.example .env
npm install
npm run dev
```

Open `http://localhost:5173`.

## Checks

```bash
npm run test -- --run
npm run build
```
